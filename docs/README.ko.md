# 네온 브레이크아웃

[English](../README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [한국어](README.ko.md) | [Русский](README.ru.md)

Fable의 전체 게임플레이, 네온 그래픽, 효과와 오디오를 `breakout-web`에 통합하고 기존 React 게임을 네이티브 TypeScript 엔진으로 교체했습니다. 데스크톱·모바일 브라우저를 지원하며 원본 Fable 디렉터리는 변경하지 않습니다.

## 개발 및 검증

```bash
bun install
bun run dev
```

```bash
bun run build
bun run test
bun run lint
bun run typecheck
```

기존 Vite 5 + TypeScript 5.6 도구 체인을 유지하며 새 의존성을 추가하지 않습니다. 빌드 결과는 표준 `dist/` 정적 사이트로 HTTP(S) 서버에서 제공해야 합니다. 더블 클릭으로 실행하는 단일 HTML 파일이 아닙니다.

## 게임

- 캠페인: 5개 챕터, 30개 스테이지, 보스 전투, 스테이지 선택과 별 수집
- 무한 모드: 시드 기반 절차 생성, 10층마다 보스 등장, 새 게임마다 새 시드 사용
- 아이템 11종: 패들 확장, 감속, 멀티볼, 관통, 확산, 레이저, 자석, 보호막, 추가 생명과 두 가지 불리한 효과인 패들 축소·공 가속
- 더블은 현재 공 수를 2배, 확산은 5배로 늘리며 총 최대 32개입니다. 각 공의 현재 위치에서 원래 진행 방향을 중심으로 부채꼴로 분열합니다
- 벽돌 배치 양옆의 통로를 통해 공이 벽돌 위쪽으로 돌아갈 수 있습니다
- UI 9개 언어 지원, 첫 방문 시 브라우저 언어를 감지하며 설정에서 변경 가능

## 조작

- 메뉴에서 캠페인, 잠금 해제된 스테이지 또는 무한 모드 선택
- 마우스: 움직여 조준하고 클릭해 발사, 발사 후 움직여 패들 조작
- 키보드: ←/→ 또는 A/D로 패들 조작, Space·↑·W로 발사, Esc·P로 일시 정지/재개
- 터치: 드래그로 조준하고 손을 떼어 발사, 발사 후 게임 영역 어디서든 드래그하여 패들 이동
- 자석에 붙은 공은 클릭, 손 떼기 또는 발사 키로 다시 발사하며 UI에서 일시 정지, 재시도, 다음 스테이지와 메인 메뉴 선택 가능

## 브라우저 저장

`localStorage`에 캠페인 잠금 해제, 별과 스테이지별 최고 점수, 무한 모드 최고 점수와 최고 클리어 층, 언어·효과음·음악 설정을 저장합니다. **새로고침으로 진행 중인 게임을 복원할 수 없습니다**. 기록을 유지하려면 브라우저 저장소가 사용 가능해야 합니다.

기존 `breakout-web` 저장 데이터는 보존하지만 스테이지 규칙이 달라 자동 이전하지 않습니다. 같은 origin(프로토콜·호스트·포트)의 기존 Fable 데이터는 `neon-breakout:v1` 키로 호환됩니다. origin을 변경해도 데이터가 이전되지는 않습니다.
