# Neon Breakout

[English](../README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [한국어](README.ko.md) | [Русский](README.ru.md)

В `breakout-web` интегрированы полный игровой процесс Fable, неоновая графика, эффекты и звук. Нативный движок TypeScript заменяет старую React-игру. Поддерживаются настольные и мобильные браузеры; исходный каталог Fable не изменяется.

## Разработка и проверка

```bash
bun install
bun run dev
```

```bash
bun run build
bun run test
bun run lint
bun run typecheck
```

Сохранён существующий набор инструментов Vite 5 + TypeScript 5.6, без новых зависимостей. Сборка создаёт обычный статический сайт в `dist/`, который нужно раздавать по HTTP(S). Это не один HTML-файл для запуска двойным щелчком.

## Игра

- Кампания: 5 глав, 30 уровней, сражения с боссами, выбор уровней и звёзды
- Бесконечный режим: процедурная генерация по seed, босс каждые 10 этажей и новый seed для каждого нового забега
- 11 предметов: расширение платформы, замедление, мультибол, пробивание, веер из пяти мячей, лазер, магнит, щит, дополнительная жизнь и два отрицательных эффекта — сужение платформы и ускорение мяча
- Двойной умножает текущее число мячей на 2, а Веер — на 5, максимум до 200 мячей; мячи расходятся веером из позиции каждого существующего мяча вокруг его исходного направления.
- Проходы по обеим сторонам блоков позволяют мячам попасть в пространство над ними.
- 9 языков интерфейса: при первом запуске определяется язык браузера, затем его можно изменить в настройках

## Управление

- В меню выберите кампанию, открытый уровень или бесконечный режим
- Мышь: двигайте для прицеливания, щёлкните для запуска; после запуска двигайте мышью для управления платформой
- Клавиатура: ←/→ или A/D управляют платформой; Пробел, ↑ или W запускают мяч; Esc или P ставят на паузу/продолжают
- Сенсорный экран: ведите пальцем для прицеливания и отпустите для запуска; затем двигайте пальцем в любом месте игрового поля для перемещения платформы
- Мяч на магните можно отпустить щелчком, отпусканием пальца или клавишей запуска; интерфейс позволяет поставить на паузу, повторить, перейти дальше или вернуться в меню

## Сохранения в браузере

`localStorage` хранит открытые уровни, звёзды и лучшие результаты кампании, рекорд очков и максимальный пройденный этаж бесконечного режима, язык, настройки эффектов и музыки. **Перезагрузка страницы не восстанавливает текущую игру**. Для сохранения рекордов хранилище браузера должно быть доступно.

Старые сохранения `breakout-web` остаются, но не переносятся автоматически из-за других правил уровней. Сохранения Fable с тем же origin (протокол, хост, порт) совместимы через ключ `neon-breakout:v1`. Смена origin не переносит сохранения.
