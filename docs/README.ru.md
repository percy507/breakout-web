# Neon Breakout

[English](../README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [한국어](README.ko.md) | [Русский](README.ru.md)

Веб-прототип breakout для проверки прицеливания, управления платформой, бонусов и темпа уровней. Работает в настольных и мобильных браузерах.

## Запуск

```bash
bun install
bun run dev
```

## Сборка

```bash
bun run build
```

## Тесты

```bash
bun run test
```

## Качество

```bash
bun run lint
bun run lint:fix
```

Стили находятся в `src/styles.less`.

## Игровой процесс

- Нажмите Старт, сначала прицельтесь, затем щёлкните или отпустите палец для запуска
- На desktop после запуска используется мышь или стрелки; на мобильных — перетаскивание
- Разбейте все разрушаемые кирпичи, чтобы пройти уровень
- После прохождения окно плавно появляется, а шары и бонусы уходят за экран
- На каждом уровне 3 жизни, есть пауза, продолжение, повтор и главное меню
- При первом визите язык определяется по браузеру; прогресс, звук и язык сохраняются в этом браузере

## Кирпичи и бонусы

- Кирпичам может понадобиться от 1 до 12 ударов
- Серые препятствия не ломаются; их форма меняет траекторию шара
- Бонусы: широкая платформа, замедление, двойной шар, пробитие и веер из пяти шаров

## Основные файлы

- `src/App.tsx`: UI, диалоги и ввод
- `src/game.ts`: правила игры и ход уровней
- `src/geometry.ts`: помощники столкновений
- `src/render.ts`: отрисовка canvas
- `src/i18n.ts`: переводы интерфейса
