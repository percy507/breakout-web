# ネオン・ブレイクアウト

[English](../README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [한국어](README.ko.md) | [Русский](README.ru.md)

Fable のゲーム内容、ネオン描画、エフェクト、音声を `breakout-web` に統合し、旧 React ゲームをネイティブ TypeScript エンジンに置き換えました。PC・モバイルブラウザーに対応し、元の Fable ディレクトリは変更しません。

## 開発・検証

```bash
bun install
bun run dev
```

```bash
bun run build
bun run test
bun run lint
bun run typecheck
```

既存の Vite 5 + TypeScript 5.6 を維持し、新しい依存関係は追加しません。出力は標準の `dist/` 静的サイトです。HTTP(S) で配信してください。ダブルクリックで動く単一 HTML ではありません。

## ゲーム内容

- キャンペーンは 5 章・30 ステージ。ボス戦、ステージ選択、星の収集に対応
- シードに基づく自動生成のエンドレスモード。10 階ごとにボス、新規プレイごとに新しいシード
- 11 種のアイテム：パドル拡大、減速、マルチボール、貫通、スプレッド、レーザー、磁力、シールド、ライフ追加、および不利なパドル縮小と加速
- ダブルは現在のボール数を 2 倍、スプレッドは 5 倍にし、合計は最大 32 個。各ボールの位置から元の進行方向を中心に扇状に分裂します
- ブロック配置の両側には、ボールが上側へ回り込める通路があります
- UI は 9 言語。初回はブラウザーの言語を使用し、設定で変更可能

## 操作

- メニューからキャンペーン、解放済みステージ、エンドレスを選択
- マウス：移動して狙い、クリックで発射。発射後は移動でパドルを操作
- キーボード：←/→ または A/D でパドル操作。Space・↑・W で発射、Esc・P で一時停止／再開
- タッチ：ドラッグで狙い、指を離して発射。発射後はプレイ領域のどこでもドラッグしてパドル操作
- 磁力で保持した球もクリック、指を離す操作、発射キーで再発射。画面から一時停止、リトライ、次のステージ、メニューを選択可能

## ブラウザーのセーブ

`localStorage` に解放状況、星、ステージ別最高得点、エンドレス最高得点と最高クリア階、言語・効果音・音楽設定を保存します。**再読み込みでプレイ中の状態は復元できません**。記録の保持にはブラウザーストレージが必要です。

旧 `breakout-web` のセーブは保持しますが、ステージルールが異なるため自動移行しません。同じ origin（スキーム・ホスト・ポート）の Fable セーブは `neon-breakout:v1` キーで引き続き利用できます。origin を変えてもセーブは転送されません。
